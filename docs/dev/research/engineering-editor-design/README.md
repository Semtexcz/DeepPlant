# Engineering Editor Figma Design

`deepplant-editor.fig` is the repository-tracked Figma design artifact for the
DeepPlant Engineering Editor. It preserves approved visual intent for the
editor's layout, hierarchy, component appearance, and visual states.

## Authority and use

This file is a visual-design input, not a source of engineering or behavioural
truth. Its use is governed by the
[frontend design-to-code workflow](../../frontend/design-to-code.md):

- the UX contract in Git owns behaviour;
- domain contracts and ADRs own engineering semantics and architecture;
- implementation issues identify the approved revision they use; and
- any conflict is reconciled before implementation.

The interaction architecture remains documented in
[Engineering Editor UX Architecture](../engineering-editor-ux.md).
