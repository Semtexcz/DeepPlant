# Contributing to DeepPlant

Thank you for helping improve DeepPlant. Please open an issue for substantial
changes, keep pull requests focused, and include tests and documentation for
behavioral changes. Maintainers accept contributions only after the pull
request confirmation is completed and the contribution is reviewed.

## Contribution terms

By submitting a contribution for inclusion in DeepPlant, you confirm that:

- it is your original work, or you are legally authorized to submit it;
- you have disclosed every known third-party component, restriction, and
  required attribution;
- it can be included in a project distributed under `AGPL-3.0-only`; and
- you accept the contributor terms in [CLA.md](CLA.md).

You keep copyright in your contribution. The CLA gives the project owner the
permissions needed to distribute accepted contributions in the AGPL community
project and, where the project owner has sufficient rights, to offer the same
code under alternative commercial terms. It does not require copyright
assignment.

Do not submit material with an incompatible licence or unclear provenance
without discussing it with a maintainer first. In particular, disclose the
source, licence, modifications, and attribution requirements for:

- engineering standards, standards-derived symbols, and schemas;
- proprietary or vendor-specific formats, including industrial project data;
- documentation, copied examples, datasets, screenshots, and sample files;
- generated or imported reference data; and
- code, icons, or other assets obtained from third parties.

Public availability is not proof that material may be redistributed. The
repository's [third-party notices](THIRD_PARTY_NOTICES.md) and existing
[standards policy](docs/standards.md) describe the evidence maintainers need.

## Pull request checklist

Before requesting review, confirm the checkbox in the pull request template,
identify provenance for any non-original material, and run the relevant
project checks (normally `make check`). Maintainers may request a separate
written grant for a substantial existing work or a contribution made on behalf
of an organization.

DeepPlant's outbound project licence remains `AGPL-3.0-only`. Nothing in the
contribution process changes rights already granted under that licence.
