# DeepPlant brand logos

This directory contains the original DeepPlant brand artwork contributed to this
repository. It is distributed with DeepPlant under `AGPL-3.0-only`; no
third-party artwork, fonts, or other attribution requirements apply. The
horizontal wordmarks contain vector outlines and have no runtime font dependency.

Use `deepplant-horizontal-master.svg` on light backgrounds as the default
horizontal logo. Use `deepplant-horizontal-black.svg` for monochrome light
backgrounds, `deepplant-horizontal-dark.svg` for dark backgrounds, and
`deepplant-horizontal-white.svg` where a monochrome white mark is required.
`deepplant-master-icon.svg` is the general square icon; use
`deepplant-favicon.svg` for favicon-sized contexts.

Project identity is governed by [TRADEMARKS.md](../../../TRADEMARKS.md).
