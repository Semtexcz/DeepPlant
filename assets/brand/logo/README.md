# DeepPlant brand logos

This directory contains project-authored DeepPlant brand artwork, distributed
with DeepPlant under `AGPL-3.0-only`. The horizontal wordmark letterforms were
generated from [Inter Bold](https://rsms.me/inter/) and converted to vector
paths. The distributed SVGs have no runtime font dependency; Inter is included
here only as artwork-generation provenance and is distributed under the
[SIL Open Font License 1.1](https://github.com/rsms/inter/blob/master/LICENSE.txt).

Use `deepplant-horizontal-master.svg` on light backgrounds as the default
horizontal logo. Use `deepplant-horizontal-black.svg` as the black-on-light
variant, `deepplant-horizontal-dark.svg` for dark backgrounds, and
`deepplant-horizontal-white.svg` as the white-on-dark variant.
`deepplant-master-icon.svg` is the general square icon; use
`deepplant-favicon.svg` for favicon-sized contexts.
