# Qt WebEngine / Chromium third-party notices

Qt WebEngine embeds Chromium. As Qt's own licensing guidance states, distributing
Qt WebEngine requires complying with **both** the Qt WebEngine licences and the
licences of the Chromium parts it contains. The Chromium notice set is large (many
hundreds of third-party components) and is generated by Chromium's own build
tooling, so it is deliberately **not** reproduced here as a hand-maintained,
necessarily-incomplete list.

## What this file records

- **The Qt WebEngine parts** are covered by the licence texts shipped alongside
  this file (`LGPL-3.0-only.txt`, `LGPL-2.0-or-later.txt`, `GPL-2.0-only.txt`,
  `GPL-3.0-only.txt`, `Qt-GPL-exception-1.0.txt`), taken from the exact
  `qtwebengine` `v6.11.2` source tag.
- **The Chromium parts** are distributed exactly as Qt WebEngine ships them,
  unmodified. Their authoritative, version-matched notice set is produced by
  upstream tooling and is available from these upstream sources at the exact
  version this application was built against:
  - Qt WebEngine `v6.11.2`: `https://code.qt.io/cgit/qt/qtwebengine.git/tag/?h=v6.11.2`
  - Qt WebEngine licensing statement:
    `https://doc.qt.io/qt-6/qtwebengine-licensing.html`
  - Chromium third-party licence generation (Chromium's own `about:credits`
    machinery): `https://chromium.googlesource.com/chromium/src/`
- The running application's Qt WebEngine engine can display the aggregated
  Chromium credits through its standard `about:credits` page, which reflects the
  exact Chromium revision compiled into the redistributed `Qt6WebEngineCore`.

## Corresponding source offer

The redistributed Qt WebEngine/Chromium binaries are unmodified upstream builds.
Their corresponding source is available from the upstream Qt and Chromium
locations recorded above. Write to the DeepPlant maintainer (see
`THIRD_PARTY_NOTICES.md`) for a written offer of the corresponding source for the
exact binaries redistributed with a specific build.

## Honest limitation (tracked compliance action)

Reproducing the complete, version-matched Chromium third-party notice set inside
the artifact as a static file is **not** claimed here: no single immutable
upstream file publishes it for a given Qt release, and inventing a partial list
would be worse than pointing at the authoritative source. This is recorded as an
open compliance action for the standalone-editor distribution rather than as a
completed obligation.
